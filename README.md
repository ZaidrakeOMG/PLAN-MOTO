# Plan Moto Mobile

App móvil/PWA hecha con React + Tailwind + Supabase.

## Si vienes de la versión anterior

Ejecuta completo `FIX_SUPABASE.sql` en **Supabase > SQL Editor**.

## Instalación nueva

Ejecuta completo `SUPABASE.sql` en **Supabase > SQL Editor**.

## Ejecutar

```bash
npm install
npm run dev
```

Cada apartado se guarda de forma independiente por `semana + apartado` en `public.plan_tareas`.
